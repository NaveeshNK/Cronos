# Cronos

Computational camera for Android — **capture → enhance → save**.

Daylight-first pipeline (v1):
- CameraX preview & capture
- Post-process: auto white-balance lean, tone curve, vibrance, local contrast, gentle sharpen
- Before / After review with strength control
- Save enhanced image to gallery

Not a clone of iPhone — a clear **finished photo** default on Android.

## Build
- Android Studio, or GitHub Actions `assembleDebug`
- Min SDK 26, Target 35
